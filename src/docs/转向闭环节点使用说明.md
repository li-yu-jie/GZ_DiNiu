# steer_closed_loop_node 使用说明（位置环 PID）

本文档说明 `src/steer_closed_loop/src/steer_closed_loop_node.cpp` 当前实现的转向位置闭环逻辑。

## 1. 节点职责

`steer_closed_loop_node` 负责：

- 订阅目标转向角：`/target_steer`（`std_msgs/msg/Float64`，单位：rad）
- 读取霍尔编码器并估算当前转向角
- 运行位置环 PID，输出方向 GPIO + PWM
- 控制刹车 GPIO（当前默认：输出 GND 为抱闸）
- 发布兼容反馈角：`/steer_position`（`std_msgs/msg/Float64`，单位：rad）
- 发布转向角话题：`/steer_angle`（`std_msgs/msg/Float64`，单位：rad）
- 发布编码器计数：`/steer_encoder_count`（`std_msgs/msg/Int64`，单位：count）

## 2. 启动状态机

上电后默认按以下顺序执行：

1. `kSeekingLeftLimit`：找左限位
2. `kReturningToZero`：左限位标定后回到 0 度
3. `kDone`：进入正常闭环控制
4. `kFailed`：启动回零保护触发后的失败态

说明：

- 左限位触发后，会把该位置标定为 `left_limit_deg`（当前 YAML 默认 `+46.0`）
- 右限位对应 `right_limit_deg`（当前 YAML 默认 `-46.0`）
- 回零完成前会忽略外部 `/target_steer` 命令
- 若找限位或回零超过保护值，节点会停车、抱闸，并进入 `kFailed`

## 3. 话题

- 输入命令：`/target_steer`（Float64，单位 rad）
- 输出反馈：`/steer_position`（Float64，单位 rad，兼容旧接口）
- 输出转向角：`/steer_angle`（Float64，单位 rad）
- 输出编码器计数：`/steer_encoder_count`（Int64，单位 count）

发送角度示例（约 20°、-30°、0°）：

```bash
ros2 topic pub -1 /target_steer std_msgs/msg/Float64 "{data: 0.349066}"
ros2 topic pub -1 /target_steer std_msgs/msg/Float64 "{data: -0.523599}"
ros2 topic pub -1 /target_steer std_msgs/msg/Float64 "{data: 0.0}"
```

查看反馈：

```bash
ros2 topic echo /steer_position
ros2 topic echo /steer_angle
ros2 topic echo /steer_encoder_count
```

## 4. 关键参数（当前默认值）

### 4.1 硬件与引脚

- `chip_path=/dev/gpiochip0`
- `hu_gpio=5`
- `hv_gpio=6`
- `hw_gpio=13`
- `dir_gpio=16`
- `invert_dir=true`（方向引脚逻辑反转；若方向正常可设为 `false`）
- `brake_gpio=12`
- `brake_active_level=0`（低电平有效，输出 GND=刹车）
- `limit_left_gpio=24`
- `limit_right_gpio=25`
- `limit_active_level=1`
- `positive_dir_hits_left_limit=true`

### 4.2 PWM 与编码器

- `pwm_chip_path=/sys/class/pwm/pwmchip0/`
- `pwm_channel=1`
- `pwm_period_ns=100000`
- `steer_angle_topic=steer_angle`
- `encoder_count_topic=steer_encoder_count`
- `encoder_counts_per_rev=9200`
- `invert_encoder=true`
- `event_debounce_us=5`

### 4.3 位置环控制

- `control_hz=50.0`
- `kp=5.5`
- `ki=0.0`
- `kd=0.0`
- `i_max=50.0`
- `position_deadband_deg=0.5`
- `max_pwm_percent=90.0`
- `max_pwm_step=12.0`
- `min_effective_pwm_percent=18.0`
- `debug_hz=2.0`

### 4.4 启动回零

- `startup_auto_home=true`
- `left_limit_deg=46.0`
- `right_limit_deg=-46.0`
- `home_seek_pwm_percent=65.0`
- `home_zero_tolerance_deg=1.0`
- `home_timeout_s=15.0`
- `home_max_travel_deg=120.0`
- `zero_offset_deg=0.0`

### 4.5 启动回零保护

启动回零保护用于防止限位开关、方向参数或编码器异常时持续驱动转向电机。

保护条件：

- `home_timeout_s=15.0`：从节点启动进入回零流程开始计时，超过 15 秒仍未完成找左限位和回 0°，立即停车。
- `home_max_travel_deg=120.0`：回零过程中编码器原始累计行程超过 120°，立即停车。

保护触发后：

- PWM 输出置 0
- 刹车 GPIO 进入抱闸状态
- 状态切换为 `failed`
- 外部 `/target_steer` 命令会继续被忽略
- 日志会打印 `startup homing failed`

恢复方式：

1. 检查左右限位 GPIO、电机方向、`positive_dir_hits_left_limit`、编码器方向。
2. 修正参数或接线后重启节点/服务。
3. 若现场机械行程确实较大，可适当增大 `home_max_travel_deg`，但应小于机械允许行程。

## 6. 调试要点

节点日志包含：

- `state`：当前状态（`seeking_left` / `returning_zero` / `ready` / `failed`）
- `pos`：当前角度
- `target`：目标角度
- `err`：角度误差
- `out%`：输出 PWM 百分比
- `L` / `R`：左右限位状态
- `B`：刹车状态（1=抱闸，0=松闸）

## 7. 常见问题

### 7.1 发了角度不动

- 可能仍在启动回零阶段（`state != ready`）
- 如果状态是 `failed`，说明启动回零保护已触发，需要检查限位/方向/编码器后重启
- 检查限位是否常态误触发
- 检查刹车电平定义是否与硬件一致（`brake_active_level`）

典型保护日志：

```text
startup homing failed: seeking left limit exceeded safety limits count=3067 pos=120.01 raw=120.01 timeout=15.0s max_travel=120.0deg
state=failed pos=121.66 target=0.00 err=0.00 out%=0.00 L=0 R=0 B=1
```

含义：

- `L=0` 表示左限位没有触发。
- `pos/raw` 已超过 `home_max_travel_deg` 限制。
- `B=1` 表示已经抱闸。

处理顺序：

1. 确认左限位开关接线和 `limit_left_gpio` 是否正确。
2. 手动触发左限位，观察日志里的 `L` 是否变为 `1`。
3. 如果电机找限位方向反了，检查 `positive_dir_hits_left_limit` 和 `invert_dir`。
4. 如果编码器角度方向反了，检查 `invert_encoder`。
5. 若机械实际行程确实超过 120°，再调大 `home_max_travel_deg`。

### 7.2 角度偏差

- 比例误差：优先校准 `encoder_counts_per_rev`
- 零点偏差：调 `zero_offset_deg`
