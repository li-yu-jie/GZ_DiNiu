# 阿克曼底盘控制说明

本文档说明本项目在阿克曼结构小车上的 `/cmd_vel` 控制链路、话题关系和常用调试命令。

## 1. 控制目标

本车采用阿克曼转向结构，外部控制统一使用 ROS 2 标准话题 `/cmd_vel`：

- `linear.x`：车体前向速度目标，单位 `m/s`
- `angular.z`：车体角速度目标，单位 `rad/s`

`motor_control_node` 会把 `linear.x` 作为驱动轮速度目标，同时按阿克曼运动学把 `angular.z` 换算成前轮目标转角，并发布到 `/target_steer`。

## 2. 控制链路

```text
/cmd_vel
  |
  v
motor_control_node
  |-- 驱动 PWM / DIR
  |-- /target_steer
          |
          v
     steer_closed_loop_node
          |-- /steer_position
          |-- /steer_angle
          |-- /steer_encoder_count

encoder_vel_node
  |-- /linear_velocity
  |-- /wheel_encoder_count

ackermann_odom_node
  输入: /linear_velocity + /steer_angle
  输出: /wheel_odom
```

## 3. 阿克曼换算

主控节点使用如下关系计算前轮转角：

```text
steer_angle = atan(wheelbase * angular_z / effective_speed)
```

其中：

- `wheelbase` 来自参数 `ackermann_wheelbase_m`
- `effective_speed` 会受 `ackermann_min_speed_m_s` 保护，避免低速时除零或转角发散；倒车低速时保留速度方向
- 输出转角会受 `ackermann_max_steer_angle_rad` 限幅

当前默认配置：

```yaml
steer_mode: ackermann
ackermann_wheelbase_m: 1.38
ackermann_min_speed_m_s: 0.12
ackermann_max_steer_angle_rad: 0.7853981634  # 45 deg
ackermann_low_speed_policy: presteer
zero_target_active_brake: false
drive_log_period_s: 1.0
drive_log_delta_threshold: 0.03
cmd_log_period_s: 1.0
cmd_log_delta_threshold: 0.02
feedback_timeout_s: 0.5
```

## 4. 一键启动

```bash
cd /root/GZ_DiNiu
source /opt/ros/humble/setup.bash
source install/setup.bash
ros2 launch motor_control_py cmd_vel_full.launch.py
```

如果系统已经由 systemd 启动了 `pigpiod`，可以避免重复启动：

```bash
ros2 launch motor_control_py cmd_vel_full.launch.py start_pigpiod:=false
```

常用启动参数：

```bash
# 使用 sudo -n 启动 pigpiod
ros2 launch motor_control_py cmd_vel_full.launch.py pigpiod_use_sudo:=true

# pigpiod 启动较慢时，延长依赖节点的启动等待时间
ros2 launch motor_control_py cmd_vel_full.launch.py pigpiod_ready_delay:=2.0

# 不启动转向闭环
ros2 launch motor_control_py cmd_vel_full.launch.py enable_steer:=false

# 不启动 IO 控制节点
ros2 launch motor_control_py cmd_vel_full.launch.py enable_io_control:=false
```

只测试驱动和转向链路，不启动 IMU：

```bash
ros2 launch motor_control_py cmd_vel_full.launch.py enable_imu:=false
```

## 5. 发布控制命令

直行：

```bash
ros2 topic pub -r 20 /cmd_vel geometry_msgs/msg/Twist \
"{linear: {x: 0.3, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"
```

前进并左转：

```bash
ros2 topic pub -r 20 /cmd_vel geometry_msgs/msg/Twist \
"{linear: {x: 0.3, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.3}}"
```

前进并右转：

```bash
ros2 topic pub -r 20 /cmd_vel geometry_msgs/msg/Twist \
"{linear: {x: 0.3, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: -0.3}}"
```

停车：

```bash
ros2 topic pub -1 /cmd_vel geometry_msgs/msg/Twist \
"{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"
```

只测试转向、不让驱动轮转动：

```bash
ros2 run motor_control_py motor_control_node --ros-args -p cmd_vel_scale:=0.0
```

快速测试流程：

1. 一键启动：

```bash
ros2 launch motor_control_py cmd_vel_full.launch.py
```

2. 发布 5 秒运动命令：

```bash
ros2 topic pub -r 20 /cmd_vel geometry_msgs/msg/Twist \
"{linear: {x: 0.3, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: -0.3}}"
```

3. 发送停车命令：

```bash
ros2 topic pub -1 /cmd_vel geometry_msgs/msg/Twist \
"{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}"
```

```bash
ros2 topic echo /linear_velocity
```

转向目标与反馈：

```bash

ros2 topic echo /steer_encoder_count
```


## 7. 常用参数

`motor_control_node`：

- `steer_mode`：默认 `ackermann`
- `cmd_vel_scale`：速度目标缩放，设为 `0.0` 可只测试转向
- `ackermann_wheelbase_m`：轴距，单位 `m`
- `ackermann_min_speed_m_s`：低速保护阈值，单位 `m/s`
- `ackermann_max_steer_angle_rad`：前轮目标转角限幅，单位 `rad`
- `ackermann_low_speed_policy`：低速/静止时 `angular.z` 的处理策略；`presteer` 表示预摆方向，`ignore` 表示忽略角速度并回 0
- `enable_steer_cmd`：是否发布 `/target_steer`
- `zero_target_active_brake`：零速目标是否允许反向 PWM 主动刹车；默认 `false`，停车时直接关闭驱动 PWM，避免停稳后后退
- `feedback_timeout_s`：速度反馈超时时间，超过后强制驱动 PWM 为 0；设为 `0.0` 可关闭
- `drive_log_period_s`：驱动闭环日志最小间隔，默认 `1.0` 秒
- `drive_log_delta_threshold`：驱动反馈、误差或输出变化超过该阈值时立即打印日志
- `cmd_log_period_s`：`/cmd_vel` 日志最小间隔，默认 `1.0` 秒；设为 `0.0` 时每条命令都打印
- `cmd_log_delta_threshold`：目标速度、角速度或转角变化超过该阈值时立即打印日志

`steer_closed_loop_node`：

- `cmd_topic`：默认 `target_steer`
- `feedback_topic`：默认 `steer_position`
- `steer_angle_topic`：默认 `steer_angle`
- `encoder_counts_per_rev`：转向编码器每圈计数
- `left_limit_deg` / `right_limit_deg`：左右机械限位角度
- `startup_auto_home`：启动后是否自动找左限位并回零
- `home_timeout_s`：启动回零最大允许时间，超时后停车并进入失败态
- `home_max_travel_deg`：启动回零最大允许编码器行程，超限后停车并进入失败态
- `kp` / `ki` / `kd`：转向位置环 PID 参数

`ackermann_odom_node`：

- `speed_topic`：默认 `linear_velocity`
- `steer_topic`：默认 `steer_angle`
- `odom_topic`：默认 `/wheel_odom`
- `wheelbase_m`：里程计模型轴距，建议与 `ackermann_wheelbase_m` 保持一致

## 8. 调试建议

1. 先确认 `pigpiod` 正常运行。
2. 启动前确认车轮悬空或车辆处在安全测试区域。
3. 第一次测试用较小速度，例如 `linear.x=0.1`。
4. 观察 `/target_steer` 与 `/steer_angle` 是否方向一致。
5. 若左右转向相反，优先检查转向电机方向参数和编码器方向参数。
6. 若里程计方向反了，优先检查驱动轮编码器 A/B 相方向。
7. 若 `/cmd_vel` 日志过多，调大 `cmd_log_period_s`；若需要详细抓每条命令，临时设为 `0.0`。
8. 若驱动闭环日志过多，调大 `drive_log_period_s`；若反馈中断，日志会提示 `linear velocity feedback timeout`。
